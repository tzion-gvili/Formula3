# Formula3 – מעבדת האלקטרוניקה ⚡

משחק לימוד אלקטרוניקה בעברית. חידונים ומשחקים קטנים עם צלילים מתוקים, אנימציות וכוכבים.

## איך משחקים

- פותחים את `index.html` בדפדפן. לא צריך להתקין שום דבר.
- או מעלים ל-GitHub Pages ופותחים בטלפון (ראו `GITHUB_PAGES_SETUP.md`).
- הכוכבים נשמרים בדפדפן. כל שלב פותח את השלב הבא.

## מבנה הקבצים

```
Formula3/
├── index.html            # הדף הראשי
├── css/style.css         # עיצוב ואנימציות
└── js/
    ├── core.js           # צלילים, קונפטי, כוכבים, תפריטים
    └── games/*.js        # משחק אחד בכל קובץ
```

## הוספת משחק חדש

יוצרים קובץ ב-`js/games/`, קוראים ל-`Games.register({...})` עם `id`, `cat`, `icon`, `title`, `desc`, `levels`, `play(stage, level, api)`, ומוסיפים תגית `<script>` ב-`index.html`.

## טכנולוגיה

HTML, CSS ו-JavaScript בלבד. הצלילים נוצרים בזמן אמת עם Web Audio API, בלי קבצי שמע.
